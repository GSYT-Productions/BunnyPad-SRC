# BunnyPad Mac App Store screenshots

Upload the three JPEG files in numbered order under the Mac screenshots section
in App Store Connect. Each image is 2880 × 1800 pixels (16:10), RGB, without alpha.

1. 01-notes.jpg — everyday note taking
2. 02-find-and-plan.jpg — planning with the native Find bar
3. 03-your-writing-style.jpg — creative writing with the Georgia font

Captured directly from BunnyPad's SwiftUI and AppKit views using temporary sample
content, a 22 pt editor font, and isolated screenshot preferences. No production
source changes or personal documents were needed. These are editor-area captures,
without desktop chrome or marketing overlays. Sample text is illustrative.

Apple screenshot specifications:
https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications

The ZIP in the parent folder contains the three upload images. Extract it before
uploading; App Store Connect accepts the individual images, not the ZIP archive.
